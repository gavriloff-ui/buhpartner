# БухПартнет — Ваш финансовый партнер

Лендинг-пейдж для сервиса бухгалтерского и финансового сопровождения бизнеса.

## О проекте
**БухПартнет** предлагает услуги по ведению бухгалтерского учета, налоговому консалтингу и антикризисному сопровождению для ИП и ООО. Сайт разработан с акцентом на доверие, понятность и удобство пользователей.

## Основные функции
- **Интерактивный калькулятор:** Позволяет пользователям быстро получить ориентировочную стоимость обслуживания на основе типа бизнеса, налоговой системы, количества сотрудников и объема операций.
- **Адаптивный дизайн:** Корректное отображение на мобильных устройствах и десктопах.
- **Блоки доверия:** Описание гарантий, кейсов и команды экспертов.
- **FAQ:** Ответы на часто задаваемые вопросы клиентов.

## Технологии
- HTML5
- CSS3 (с использованием переменных и Flexbox)
- JavaScript (для калькулятора и интерактивных элементов)

## Как запустить
Просто откройте файл `index.html` в любом современном браузере.
