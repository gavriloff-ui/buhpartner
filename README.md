# БухПартнет — Ваш финансовый партнер

БухПартнет — это профессиональный сервис бухгалтерского и налогового сопровождения, предназначенный для малого и среднего бизнеса. Наш проект предоставляет комплексные решения для предпринимателей (ИП) и юридических лиц (ООО), помогая им сосредоточиться на развитии своего дела, пока мы берем на себя всю финансовую и бюрократическую нагрузку.

## 🚀 О проекте

Главная цель проекта — обеспечить клиентам полную финансовую безопасность. Лендинг построен на принципах доверия и прозрачности. Он включает в себя все необходимые инструменты для первого знакомства с услугами компании: от оценки стоимости до детального ознакомления с кейсами и командой экспертов.

## ✨ Основные функции

### 1. Интерактивный калькулятор стоимости
Уникальный инструмент, который позволяет потенциальным клиентам мгновенно получить ориентировочную стоимость сопровождения.
*   **Параметры расчета:** Тип бизнеса (ИП/ООО), система налогообложения (УСН, Патент, ОСНО), количество сотрудников и объем ежемесячных операций.
*   **Логика:** Калькулятор использует динамические коэффициенты для расчета базовой стоимости, обеспечивая быструю оценку перед первым звонком.

### 2. Сегментированные услуги
Разделение предложений для разных категорий бизнеса:
*   **Для ИП:** Упрощенный учет, работа с патентом, налоговая оптимизация для микробизнеса.
*   **Для ООО:** Полный цикл бухгалтерского сопровождения, работа со сложными системами налогообложения, антикризисное управление.

### 3. Блоки доверия и экспертности
*   **Гарантии:** Четкое описание юридической ответственности и политики конфиденциальности.
*   **Кейсы:** Реальные примеры успешного решения сложных задач (например, спасение бизнеса от блокировок ФНС).
*   **Команда:** Представление ключевых экспертов с указанием их специализации и опыта.

### 4. Адаптивность и UX
*   Полная поддержка мобильных устройств.
*   Современная цветовая палитра (Dark Blue & Emerald) для создания ощущения надежности и роста.
*   Интерактивные элементы (FAQ аккордеон, плавные переходы).

## 🛠 Технологический стек

*   **Frontend:**
    *   **HTML5:** Семантическая разметка для лучшего SEO и доступности.
    *   **CSS3:** Использование CSS-переменных для быстрой настройки темы и Flexbox для сетки.
    *   **Vanilla JavaScript:** Чистый JS для реализации логики калькулятора и интерактивности без лишних зависимостей.

## ⚙️ Быстрый старт

### Требования
Для запуска проекта не требуется установка дополнительных сред или серверов. Нужен только любой современный веб-браузер.

### Инструкция
1.  Склонируйте репозиторий:
    ```bash
    git clone https://github.com/gavriloff-ui/buhpartner.git
    ```
2.  Перейдите в директорию проекта:
    ```bash
    cd buhpartner
    ```
3.  Откройте файл `index.html` в браузере.
