# БухПартнет — Ваш финансовый партнер

ООО «БухПартнер» — профессиональный сервис бухгалтерского и налогового сопровождения для малого и среднего бизнеса. Мы помогаем предпринимателям (ИП) и юридическим лицам (ООО) сосредоточиться на развитии дела, пока мы берем на себя учет, налоги и взаимодействие с ФНС.
